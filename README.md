# Persona Manager (SillyTavern 확장)

페르소나 설명문을 **항목**과 **선택지**로 나눠 쓰고, 조합을 **버전**으로 저장해 한 번에 바꾸고,
편집 **이력**을 되돌리고, 페르소나마다 **이미지 에셋**을 두어 채팅에 넣는 SillyTavern 확장입니다.

- 채팅 입력창 옆 아이콘 하나로 페르소나·버전을 바로 전환
- 설명문을 외모 / 성격 / 말투 … 같은 항목으로 나누고, 항목마다 여러 선택지를 두고 고르기
- 현재 조합을 버전으로 저장. 버전마다 태그, 사용할 에셋, 페르소나 이미지까지 지정
- 본문을 고칠 때마다 이전 내용을 이력으로 보관하고, 차이를 보며 되돌리기
- 페르소나별 이미지 폴더. `{{pimg::이름}}` 태그로 채팅에 그림 삽입, `{{persona_assets}}` 매크로로 모델에게 목록 전달
- 그룹·태그·검색·정렬·타일 보기로 페르소나가 서른 개여도 찾기 쉽게
- 채팅 언어에 맞춰 페르소나 이름 자동 전환 (한국어 / 일본어 / 중국어 / 영어)

> **English summary.** A SillyTavern extension that composes a persona description from
> named items (each with selectable choices), saves combinations as versions, keeps an
> edit history with diffs, and attaches per-persona image assets that render in chat via
> `{{pimg::name}}`. Korean UI. No build step, no dependencies: copy the folder into
> `public/scripts/extensions/third-party/` and enable it. `npm test` runs the pure-module
> suite; `npm run smoke` drives every screen in headless Chromium.

---

## 설치

1. SillyTavern의 **확장 → 확장 설치**에 저장소 주소를 넣거나, 이 폴더를
   `SillyTavern/public/scripts/extensions/third-party/st-persona-manager/` 에 둡니다.
2. 확장 목록에서 **Persona Manager**를 켭니다.
3. 채팅 입력창 왼쪽에 페르소나 아이콘이 나타나면 끝입니다.

빌드 과정도, 외부 패키지도 없습니다. 브라우저가 `color-mix()`, `:has()`, `<dialog>`를
지원해야 합니다 (Chromium 111+, Safari 16.4+, Firefox 121+; 최근 Android 브라우저는 모두 해당).

## 3분 안에 시작하기

1. **아이콘을 눌러** 빠른 전환 패널을 엽니다. 현재 페르소나와 목록이 보입니다.
2. **버전 ▸ 현재 페르소나 관리 시작**을 누릅니다. 기존 설명문은 한 글자도 바뀌지 않은 채
   항목으로 들어옵니다. 설명문에 `## 외모`, `[성격]`, `말투:` 같은 제목 줄이 있으면 그 제목에
   맞는 항목으로 자동 분류됩니다.
3. 패널 아래 **편집**을 눌러 관리자 화면을 엽니다. 항목을 열고 **편집**으로 본문을 쓰거나,
   **전문**으로 설명문 전체를 한 화면에서 고칩니다. 저장하면 SillyTavern의 설명문이 즉시
   바뀝니다.
4. 마음에 드는 조합이 되면 **버전 탭 ▸ 현재 구성을 버전으로 저장**. 이제 빠른 패널에서
   버전 이름 한 번 눌러 조합을 통째로 바꿀 수 있습니다.

## 화면 안내

### 빠른 전환 패널 (입력창 아이콘)

| 구역 | 하는 일 |
| --- | --- |
| 현재 | 지금 플레이 중인 페르소나와 적용된 버전. 조합이 버전에서 벗어나면 `(수정 있음)` |
| 버전 | 저장된 버전 목록. 한 번 누르면 적용, `⋯`로 이름 변경·덮어쓰기·복제·순서·삭제 |
| 언어별 이름 | 언어마다 등록한 이름을 한 번에 적용. 자동 적용 스위치 |
| 페르소나 | SillyTavern 페르소나 목록. 정렬, 목록/타일 보기, 검색(초성·오타 허용), 그룹 칩 |
| 선택 | 여러 페르소나를 골라 태그 추가·삭제, 그룹에 넣기, 관리 데이터 삭제 |
| 그룹 | 행을 눌러 그 페르소나를 그룹에 넣고 빼기, 새 그룹 만들기 |
| 아래 단추 | 관리자 화면의 각 탭으로 바로 이동 |

### 관리자 화면

| 탭 | 하는 일 |
| --- | --- |
| 편집 | 항목과 선택지. 활성 선택지 고르기, 본문 편집, 전문 보기, 제목별 분류, 기본 항목 채우기, 항목 제목 형식(없음 / `이름:` / `## 이름`), 태그, 페르소나 이름·이미지·복제, 언어별 이름, 프롬프트 배치(위치·깊이·역할·월드인포) |
| 버전 | 버전 저장·적용·수정. 버전마다 태그, 사용할 에셋, 적용 시 바뀔 페르소나 이미지와 그 위치·크기. **새 버전 만들기**: 본문을 드래그해 바꿀 부분만 고쳐 새 버전으로 |
| 이력 | 선택지마다 지난 저장본. 이전 / 지금 / 차이 보기, 그 시점으로 되돌리기. 아래에 변경 기록 |
| 에셋 | 이 페르소나의 이미지 폴더. 올리기, 삭제, **채팅에 넣기** |
| 그룹 | 그룹 만들기·이름 변경·삭제, 현재 페르소나 붙이기·떼기 |

상단의 페르소나 이름을 누르면 **다른 페르소나로 이동**합니다. 플레이 중이 아닌 페르소나도
편집할 수 있고, 그쪽의 설명문에만 반영됩니다.

### 설정 서랍 (확장 설정)

여섯 구역으로 나뉩니다: **표시**(아이콘, 목록의 버전 표시, 에셋 테두리), **페르소나 목록**
(타일 열·행·모양, 한 화면 개수), **이력 보관**(개수·총량·기간·병합 시간), **설명문**(언어별
이름 자동 적용, 가져올 때 항목 분류, 새 페르소나의 제목 형식), **에셋 매크로**(주입 여부,
지시문 템플릿), **진단과 데이터**(식별 방식, 저장 사용량, 빈 페르소나 정리, 이력·기록 비우기,
설정 내보내기·가져오기, 정규식 내보내기).

## 핵심 개념

- **항목(item)** — 설명문을 이루는 조각. 외모, 성격, 말투처럼 이름이 있습니다. 순서가 곧
  프롬프트 순서입니다.
- **선택지(choice)** — 한 항목이 가질 수 있는 여러 본문. 항목마다 하나가 **활성**이고, 활성
  선택지의 본문만 프롬프트에 들어갑니다. 빈 본문은 제목까지 함께 빠집니다.
- **버전(version)** — "항목마다 어느 선택지"의 조합을 이름 붙여 저장한 것. 본문을 복사하지
  않고 가리키기만 하므로, 본문을 고치면 그 선택지를 쓰는 모든 버전에 반영됩니다.
- **이력(history)** — 선택지 본문을 저장할 때마다 이전 본문을 보관합니다. 개수·총량·기간
  상한은 설정에서 정하고, 상한을 넘겨 정리되면 변경 기록에 한 줄 남습니다.
- **에셋(asset)** — 페르소나마다 하나씩 갖는 이미지 폴더(SillyTavern의 sprites 저장소,
  `persona_<아바타 파일명>` 폴더). 채팅 본문의 `{{pimg::이름}}`은 그 폴더의 그림으로
  그려지고, 저장된 메시지는 태그 그대로 남습니다. `{{pimg::폴더/이름}}`처럼 폴더를 적으면
  다른 페르소나의 그림도 됩니다.
- **매크로** — `{{persona_assets}}`는 현재 페르소나(와 적용된 버전)가 쓰는 에셋 이름 목록,
  `{{persona_asset_prompt}}`는 설정의 지시문 템플릿에 그 목록을 넣은 글입니다. 캐릭터 카드나
  시스템 프롬프트에 넣어 모델에게 그림 사용법을 알려 줍니다.
- **외부 수정** — SillyTavern의 페르소나 화면에서 설명문을 직접 고치면 관리자 내용과
  달라집니다. 패널이 이를 알리고, **되돌리기**(관리자 내용으로 다시 쓰기)와
  **가져오기**(바깥 내용을 본문이 든 항목으로 가져오기)를 제공합니다.

## 데이터와 백업

- 모든 데이터는 SillyTavern의 `settings.json` 안 `extensionSettings["persona-manager"]`에
  저장됩니다. 페르소나 설명문 자체는 SillyTavern의 자리에 그대로 쓰이므로, 이 확장을 꺼도
  마지막으로 조합한 설명문은 남습니다.
- **설정 내보내기**로 전체를 JSON 파일로 받고, **설정 가져오기**로 통째로 되돌립니다.
  가져오기는 현재 데이터를 모두 대체하므로 먼저 내보내기를 권합니다.
- 버전에 지정한 이미지를 처음 적용할 때 원래 페르소나 이미지를 에셋 폴더에
  `pm-backup-…` 이름으로 보관합니다. **편집 탭 ▸ 페르소나 ▸ 원본 되돌리기**로 복원합니다.
- 더 새로운 판이 만든 데이터는 **읽기 전용**으로 열립니다. 이 판으로 다시 쓰지 않으니 확장을
  최신으로 올리면 그대로 이어집니다.

## 자주 묻는 상황

| 화면에 보이는 말 | 뜻과 해결 |
| --- | --- |
| 이름이 같은 페르소나가 여럿이라 … 편집 잠금 | 같은 이름의 페르소나가 둘 이상인데 어느 쪽이 활성인지 확정할 수 없습니다. 페르소나 이름을 다르게 하거나, 설정 서랍의 **페르소나 식별**이 "정밀" 또는 "화면"이 되는 SillyTavern 빌드를 쓰면 풀립니다. 전환은 잠기지 않습니다. |
| 더 새로운 판이 만든 데이터라 읽기 전용 | 확장을 최신으로 올리세요. 데이터는 손대지 않습니다. |
| 외부에서 설명문 직접 수정 | 위 "외부 수정" 참고. |
| 프롬프트에서 빠지는 빈 항목 N개 | 활성 선택지의 본문이 빈 항목입니다. 본문을 쓰거나 항목을 지우세요. |
| 지정된 선택지 없음 (버전) | 버전이 가리키던 선택지가 삭제됐습니다. 버전 행의 `⋯`에서 다시 고르세요. |
| 에셋 목록 불러오기 실패 | sprites API가 응답하지 않았습니다. **다시 시도**, 또는 채팅을 다시 열면 재시도합니다. |
| `{{pimg::…}}`가 글자로 남음 | 그 이름의 그림이 폴더에 없습니다. 에셋 탭의 이름과 같은지 확인하세요 (확장자는 빼도 됩니다). |

## 개발

```
npm test        # 문법 검사 + 순수 모듈 단위 테스트 (node:test, 의존성 없음)
npm run smoke   # 헤드리스 Chromium으로 모든 화면 구동 (playwright 필요: npm i -D playwright)
```

`test/browser/host.html`은 SillyTavern을 흉내 내는 최소 페이지이고, `smoke.mjs`는
폰(411px)과 데스크톱(1280px) 너비에서 패널·관리자·설정을 차례로 누르며 상태를 검사하고
스크린샷을 `test/browser/out/`에 남깁니다.

### 구조

```
index.js                 진입점. 이벤트 연결, 채팅 그림 렌더링, 해제 훅
modules/
  state.js               "지금 어느 페르소나이고 그 데이터는 무엇인가"를 아는 유일한 곳
  ctx.js                 활성 페르소나 식별 (정밀 API → 화면 → 채팅 고정 → 이름)
  store.js               데이터 모델, 기본값, 스키마 이행
  compose.js             항목을 설명문으로 조합해 SillyTavern에 쓰기
  classify.js            설명문의 제목 줄을 항목으로 분류
  history.js             이력 스냅샷, 상한, 되돌리기, 단어 단위 diff
  roster.js              페르소나 목록 정렬·그룹
  search-pure.js         초성·오타 허용 검색, 언어 판별, 페이지 나누기
  framing.js             페르소나 이미지 위치·크기(크롭) 계산
  assets.js              sprites API, {{pimg::}} 렌더링, 아바타 쓰기, 매크로
  manager-pure.js        관리자 화면의 순수 로직
  quickbar-pure.js       빠른 패널의 순수 로직
  dom.js                 세 화면이 함께 쓰는 DOM 도우미 (탭 대상, 한글 조립, 제스처 안전 재그리기)
  quickbar.js            빠른 패널 (DOM)
  manager.js             관리자 화면 (DOM)
  settings-ui.js         설정 서랍 (DOM)
  strings.js             사용자가 읽는 모든 문장
style.css                SillyTavern 테마 변수에서 색을 끌어오는 스타일
```

`*-pure.js`와 `store/compose/classify/history/roster/search-pure/framing`은 DOM도 SillyTavern도
읽지 않아 Node에서 그대로 테스트됩니다. DOM 모듈의 핸들러는 컨텍스트·상태·노드를 붙들지
않고 실행 시점에 다시 읽습니다 — 페르소나가 바뀐 뒤 엉뚱한 페르소나에 쓰는 일을 막는
규칙입니다.
