# Persona Manager

SillyTavern 페르소나 설명문을 항목별로 나눠 관리하고, 항목 조합을 버전으로 저장해 한 번에 바꾸는 확장. 페르소나마다 그림 폴더를 두고 채팅에 그림 삽입 가능.

> **English.** A SillyTavern extension that splits a persona description into named items
> with selectable choices, saves combinations as versions, keeps an edit history, and gives
> each persona an image folder whose pictures render in chat via `{{pimg::name}}`.
> Korean UI. No build step and no runtime dependencies.

## 주요 기능 7가지

- 입력창 옆 아이콘 하나로 페르소나·버전 전환
- 설명문을 외모, 성격, 말투 같은 **항목**으로 나누고, 항목마다 여러 **선택지** 중 하나 사용
- 현재 조합을 **버전**으로 저장. 버전마다 페르소나 이미지와 위치·크기 지정 가능
- 본문 저장 때마다 이전 본문을 **이력**으로 보관. 차이 비교와 되돌리기 가능
- 페르소나 이미지 교체 때 위치·크기 조절, 모든 화면에 즉시 반영
- 대화 언어에 맞춰 페르소나 이름 자동 변경 (한국어, 일본어, 중국어, 영어)
- 페르소나나 이름을 바꾼 뒤에도, 아직 답하지 않은 첫 메시지(그리팅)와 스와이프의 `{{user}}` 자리에 현재 이름 반영

## 설치 3단계

1. SillyTavern **확장** 메뉴의 **확장 프로그램 설치**에 `https://github.com/Penterson/st-persona-manager` 입력하기.
   직접 넣을 때는 이 폴더를 `SillyTavern/public/scripts/extensions/third-party/st-persona-manager/`에 복사하기.
2. 확장 목록에서 **Persona Manager** 켜기.
3. 입력창 왼쪽의 페르소나 아이콘 확인하기.

| 항목 | 내용 |
| --- | --- |
| 업데이트 | 자동 업데이트 꺼짐. SillyTavern **확장 프로그램 관리** 화면에서 직접 업데이트하기 |
| 지원 브라우저 | Chromium 111 이상, Safari 16.4 이상, Firefox 121 이상, Android 삼성 인터넷 22 이상 |
| 테마 색 | 삼성 인터넷 24 이하(Chromium 118 이하)와 Firefox 127 이하에서는 패널 바탕색·글자색이 SillyTavern 테마 대신 기기의 밝은/어두운 모드를 따름 |
| 코드 대조 기준 | SillyTavern 1.19.0 소스 (`/persona-set` 슬래시 명령, 페르소나 이벤트, sprites API, 아바타 자르기 업로드) |

## 처음 사용 4단계

1. SillyTavern에서 관리할 페르소나 선택하기.
2. 입력창 옆 아이콘 누르기 → 빠른 패널의 **버전** 제목 눌러 펼치기 → **현재 페르소나 관리 시작** 누르기.
   기존 설명문이 항목으로 들어감. 나누는 방식은 아래 "설명문 가져오기 방식 3가지" 참고하기.
3. 패널 아래 **편집** 누르기 → 관리자 화면에서 항목 펼치기 → 선택지의 **편집** → 본문 수정 → **저장**.
   저장 즉시 SillyTavern 설명문에 반영됨.
4. 원하는 조합이 되면 버전 탭에서 **현재 구성을 버전으로 저장** 누르기.
   이후 빠른 패널에서 버전 이름을 한 번 누르면 조합 전체가 바뀜.

## 용어 5개

| 용어 | 뜻 |
| --- | --- |
| 항목 | 설명문의 한 조각(외모, 성격 등). 항목 순서가 곧 프롬프트 순서 |
| 선택지 | 한 항목에 둘 수 있는 여러 본문. 항목마다 하나만 사용. 본문이 빈 선택지는 제목째 프롬프트에서 빠짐 |
| 버전 | 항목마다 어떤 선택지를 쓸지 정한 조합. 본문을 복사하지 않고 가리키기만 하므로, 본문을 고치면 해당 선택지를 쓰는 모든 버전에 반영 |
| 이력 | 본문을 저장할 때 보관되는 이전 본문 |
| 에셋 | 페르소나별 그림 폴더에 올린 그림. 폴더는 서버의 `characters/persona_<아바타 파일 이름(확장자 제외)>`(SillyTavern sprites 저장소) |

## 설명문 가져오기 방식 3가지

**현재 페르소나 관리 시작**을 누를 때 기존 설명문을 항목으로 나누는 방식. 설정 서랍 ▸ 설명문 ▸ **관리 시작 시 설명문 가져오기**에서 선택하기.

| 방식 | 결과 |
| --- | --- |
| 원래 항목 그대로 (기본) | 설명문이 이미 제목으로 나뉘어 있으면 그 제목의 이름·순서·모양 그대로 항목 구성. 첫 제목 앞의 글은 제목 없는 `머리말` 항목. 다시 조합한 글이 원래 글과 줄 단위로 같을 때만 적용. 다르면 첫 항목에 전체 배치 |
| 한 항목에 통째로 | 설명문 전체를 첫 항목에 배치 |
| 기본 항목에 맞춰 분류 | 제목 아래 글을 외모·성격 같은 기본 항목으로 이동. 설명문의 순서와 제목 모양이 바뀜 |

- 제목으로 인정하는 모양 5가지(우선순위 순): `## 제목`, `<제목>…</제목>`, `[제목]`, `**제목**`, `제목:`.
- 같은 모양이 2번 이상 쓰여야 나뉜 설명문으로 판단. 마크다운은 2번 이상 쓰인 가장 얕은 단계 기준.
- 여러 모양이 섞여 있으면 2번 이상 쓰인 모양 중 우선순위가 가장 높은 모양으로 나누고, 나머지 모양의 제목은 본문 글로 유지.
- 본문 없는 제목이 있거나 같은 모양의 제목이 서로 다르게 쓰였으면(`**특징:**`과 `**취미**`) 재현 불가로 첫 항목에 전체 배치.
- 원래 항목 그대로, 한 항목에 통째로: 설명문 글자 변경 없음. 빈 줄 배치만 다음 본문 저장 때 정리될 수 있음.

이미 관리 중인 페르소나는 편집 탭의 단추 2개 사용하기.

| 단추 | 동작 |
| --- | --- |
| 원래 항목으로 재구성 | 본문이 한 항목의 한 선택지에만 있을 때 사용 가능. 그 본문의 제목대로 항목을 새로 구성하고 저장된 버전도 새 항목을 가리키도록 수정. 기존 항목·선택지는 삭제되고 이전 본문은 첫 항목의 이력에 보관(이력 보관 개수가 0이면 미보관) |
| 제목별 분류 | 본문 속 제목 줄(`## 외모`, `[외모]`, `외모:`) 아래 글을 같은 이름 항목의 본문 끝에 추가. 이름이 맞는 항목이 없는 제목은 새 항목으로 생성 |

- 재구성 뒤 이력에서 이전 본문을 되돌리면 첫 항목에 전체 본문이 다시 들어가 내용이 중복됨.

## 전문 한 번에 고치기

편집 탭 ▸ **전문** ▸ 위쪽 **전문** 단추. 설명문 전체가 프롬프트에 들어가는 모양 그대로 한 칸에 표시됨. 여러 항목을 한 번에 고친 뒤 **전체 저장** 누르기.

- 저장 때 항목 제목 줄(`## 외모` 등, 제목 형식 설정에 따름) 기준으로 나눠 각 항목의 활성 선택지에 저장. 바뀐 본문만 저장되고 이전 본문은 이력에 보관.
- 항목을 비우려면 제목 줄은 두고 본문만 지우기. 본문이 빈 항목은 제목 줄을 항목 순서에 맞게 직접 입력해 채우기.
- 저장 거부 3가지: 본문이 든 항목의 제목 줄을 지움, 제목 줄 순서를 바꾸거나 같은 제목 줄을 두 번 씀, 첫 제목 줄 앞에 글을 씀(머리말 항목이 없을 때). 글은 칸에 그대로 남음.
- 항목 제목 형식이 `없음`이고 항목이 둘 이상이면 나눌 기준이 없어 읽기 전용.
- **항목별** 단추로 돌아갈 때도 같은 기준으로 나눠 항목별 칸에 반영.
- **전체 비우기**: 확인 없이 모든 항목 본문을 한 번에 비움(항목별·전문 보기 모두). **전체 저장** 전까지 미반영.
- **비우기**(항목별 보기, 항목마다): 해당 항목 본문만 확인 없이 비움.
- **되돌리기**: 비우기를 최근 것부터 하나씩 취소. 단추의 숫자는 되돌릴 수 있는 횟수. 저장한 뒤에도 전문 화면을 나가기 전까지는 되돌린 다음 다시 저장하면 원래대로 복구.

## 항목 한 번에 지우기

편집 탭 ▸ **항목 선택** → 항목마다 체크 상자 표시 → 지울 항목 체크(또는 **전체 선택**) → **선택 항목 삭제 (N)** → 확인.

- 항목의 선택지와 이력까지 함께 삭제. 되돌리기 불가이므로 필요하면 먼저 설정 서랍의 **설정 내보내기**로 백업하기.
- 전부 지우면 빈 `본문` 항목 하나가 남음(페르소나에는 항목이 최소 1개 필요). 여기에 설명문 전체를 붙여 넣고 **원래 항목으로 재구성**을 누르면 제목대로 항목을 새로 구성.
- 검색 중의 **전체 선택**은 검색 결과에 보이는 항목만 선택.

## 화면 3개

### 빠른 패널 (입력창 옆 아이콘)

| 구역 | 내용 |
| --- | --- |
| 현재 | 플레이 중인 페르소나와 적용된 버전. 조합이 버전과 다르면 `(수정 있음)` |
| 버전 | 버전 이름을 누르면 적용. `⋯`에서 이름 변경, 덮어쓰기, 복제, 순서, 삭제 |
| 언어별 이름 | 언어마다 등록한 이름 바로 적용. 자동 적용 스위치 |
| 페르소나 | 목록·타일 보기, 정렬, 검색(초성·오타 허용), 그룹 칩, 여러 개 선택(**선택**), 그룹 지정(**그룹**) |
| 바로가기 6개 | 관리자 화면의 편집·버전·이력·에셋·그룹 탭과 항목 검색. 목록을 내려도 패널 아래에 고정 |

### 관리자 화면 (탭 5개)

| 탭 | 내용 |
| --- | --- |
| 편집 | 항목·선택지 편집, **전문**(항목별 칸 또는 프롬프트에 들어가는 그대로 한 칸에서 편집), **항목 선택**(여러 항목 한 번에 삭제), 제목별 분류, 원래 항목으로 재구성, 기본 항목 채우기, 항목 제목 형식, 태그, 페르소나 이름·이미지·복제·새 페르소나 생성, 언어별 이름, 프롬프트 배치 |
| 버전 | 버전 저장·적용. 버전마다 태그, 쓸 에셋, 적용 때 바꿀 페르소나 이미지와 위치·크기 |
| 이력 | 선택지별 지난 본문. 이전·지금·차이 보기, 되돌리기, 변경 기록 |
| 에셋 | 페르소나 그림 폴더. 이미지 업로드, 삭제, 입력창에 넣기 |
| 그룹 | 그룹 만들기·이름 변경·삭제, 페르소나에 그룹 붙이기·떼기 |

- 화면 위 페르소나 이름 누르기 → 다른 페르소나로 이동. 플레이 중이 아닌 페르소나도 편집 가능.

### 설정 서랍 (구역 6개)

SillyTavern 확장 메뉴 안의 **페르소나 관리자** 서랍. 구역은 표시, 페르소나 목록, 이력 보관, 설명문, 에셋 매크로, 진단과 데이터.

## 이미지 기능 5가지

| 기능 | 사용법 |
| --- | --- |
| 이미지 교체 | 편집 탭 ▸ 페르소나 ▸ 이미지 행의 **교체** → 파일 선택 → 위치·크기 조절 창에서 끌어서 위치, 두 손가락·휠·막대로 확대 → **현재 위치로 적용** 또는 **원본 그대로 적용**. 입력창 아이콘, 패널, 관리자, SillyTavern 페르소나 목록과 채팅 아바타에 새로고침 없이 반영 |
| 버전별 이미지 | 에셋 탭에서 그림 업로드 → 버전 탭에서 버전 행 열기 → **이미지 지정**. **위치·크기 조절**로 틀을 맞추면 해당 버전 적용 때 잘린 그림이 아바타로 들어감 |
| 원본 되돌리기 | 버전 이미지를 처음 적용할 때 원래 아바타를 에셋 폴더에 `pm-backup-…` 이름으로 보관. 편집 탭 ▸ 페르소나 ▸ **원본 되돌리기**로 복원 |
| 채팅에 그림 넣기 | 채팅 메시지에 `{{pimg::이름}}` 입력. 이름은 파일 이름에서 확장자를 뺀 것, 대소문자 구분 없음. `{{pimg::폴더/이름}}`은 다른 페르소나의 그림. 에셋 탭 **입력창에 넣기**로 태그 입력. 저장된 메시지에는 태그 그대로 유지 |
| 매크로 2개 | `{{persona_assets}}`는 쓸 수 있는 그림 이름 목록, `{{persona_asset_prompt}}`는 그 목록을 넣은 안내문. 캐릭터 카드나 시스템 프롬프트에 넣어 모델에게 그림 사용법 전달 |

- 이미지 **교체**는 이전 그림을 보관하지 않음. 교체 결과는 되돌리기 불가.

## 언어별 이름 자동 적용

- 이름 등록: 편집 탭 ▸ 언어별 이름 ▸ 언어 행 누르기 → 이름 입력하기.
- 자동 적용은 처음부터 켜짐. 켜져 있으면 대화 언어에 맞춰 SillyTavern 페르소나 이름 자체를 변경.
- 끄기: 빠른 패널 ▸ 언어별 이름 ▸ 자동 적용 스위치, 또는 설정 서랍.
- 현재 판단 결과: 편집 탭 ▸ 언어별 이름의 **지금 대화 언어**.

| 판단 근거 | 비중 |
| --- | --- |
| 내가 보낸 메시지 | 5 (가장 큼) |
| 캐릭터 답장 | 3 |
| 첫 메시지(그리팅), 캐릭터 카드(설명·성격·시나리오) | 각 1.5 |
| 캐릭터 이름 | 1 |
| 내 페르소나 설명 | 0.5 (가장 작음) |

- 글이 짧으면 비중이 줄어듦. 내 메시지는 라틴 문자 30자(한글 10자)부터 비중 5 전체 적용. 한글·가나·한자 1자는 라틴 문자 3자로 계산.
- 그래서 새 채팅에서 그리팅이 한 줄뿐이어도 캐릭터 정보로 판단하고, 내가 다른 언어로 30자(한글 10자) 이상 쓰면 그 언어를 따름.
- `{{user}}` 같은 매크로, HTML 태그, 링크는 판단에서 제외.
- 같은 이름의 페르소나가 있거나 대화 속 인물과 이름이 같으면 변경 없음.

## 그리팅의 `{{user}}` 이름 맞춤

- SillyTavern은 첫 메시지를 처음 그릴 때 `{{user}}`를 그때의 이름으로 바꿔 저장함. 그 뒤 이름을 바꾸거나 다른 페르소나로 바꾸면 그리팅과 스와이프에 예전 이름이 남음.
- 대상: 아직 답하지 않은 그리팅. 1:1 채팅만(그룹 채팅은 SillyTavern이 직접 다시 불러옴).
- 캐릭터 카드의 그리팅과 스와이프를 맞춰 볼 수 있으면 카드 원문에서 `{{user}}`가 있던 자리만 현재 이름으로 수정. 원문에 글자로 적힌 같은 단어(예: 고양이 이름 Alice)는 유지. 모델이 새로 만든 스와이프는 변경 없음.
- 맞춰 볼 수 없으면(채팅을 시작한 뒤 카드의 그리팅을 고친 경우) 이번 세션에 쓴 이름과 현재 페르소나의 언어별 이름만 현재 이름으로 교체.

## SillyTavern 페르소나 화면에서 고치기 (자동 반영)

SillyTavern 페르소나 화면의 설명문 칸에서 직접 고쳐도 항목 본문에 자동 반영. 입력을 멈추고 약 0.7초 뒤 반영.

- 본문이 한 항목에만 있으면 고친 글 전체가 해당 항목으로. 여러 항목에 있으면 항목 제목 줄(`## 외모` 등) 기준으로 나눠 각 항목으로.
- 이전 본문은 이력에 보관(편집 병합 시간 안에 이어서 고친 중간 본문은 한 번만 보관).
- SillyTavern 칸의 글은 고친 그대로 유지. 입력 중에 글이나 커서가 바뀌지 않음.
- 반영 불가 3가지: 제목 줄이 지워짐, 제목 줄 순서가 바뀜, 본문이 여러 항목에 있는데 항목 제목 형식이 `없음`. 이때는 아래 외부 수정 알림이 이유와 함께 표시됨. 제목 줄을 되살리면 다음 입력 때 다시 자동 반영.
- 끄기: 설정 서랍 ▸ 설명문 ▸ **SillyTavern에서 고친 설명문 자동 반영**. 끄면 예전처럼 알림에서 직접 선택.

## 외부 수정 처리 3가지

자동 반영이 꺼져 있거나 반영할 수 없을 때, 패널과 관리자에 `외부에서 설명문 직접 수정` 알림 표시.

| 선택 | 결과 |
| --- | --- |
| 되돌리기 | 설명문을 관리자 내용으로 교체. 외부 수정 내용은 `외부 수정 MM-DD HH:mm` 선택지로 보관 |
| 가져오기 | 외부 수정 내용을 항목 본문으로 반영(기존 본문은 이력에 보관). 본문이 든 항목이 하나면 해당 항목에, 없으면 첫 항목에 전체 반영. 여럿이면 현재 항목 제목 줄 기준으로 나눠 항목마다 반영. 제목 줄이 지워졌거나 순서가 바뀌었으면, 또는 항목 제목이 `없음`이면 가져오기 불가 |
| 나중에 | 빠른 패널 알림만 닫힘. 이후 본문 저장, 활성 선택지 변경, 버전 적용처럼 조합이 바뀌는 작업을 하면 외부 수정 내용을 `외부 수정 MM-DD HH:mm` 선택지(본문이 든 항목이 하나면 해당 항목, 아니면 첫 항목)로 보관한 뒤 교체. 태그, 버전 이름처럼 조합과 무관한 작업은 설명문을 건드리지 않음 |

## 데이터와 백업

- 확장 데이터: SillyTavern `settings.json`의 `extension_settings["persona-manager"]`.
- 설명문 자체는 SillyTavern 페르소나 설명 칸에 저장되므로 확장을 꺼도 마지막 설명문 유지.
- 그림 파일: 서버의 에셋 폴더에 따로 저장. **설정 내보내기**에 포함되지 않음.
- **설정 내보내기**로 확장 데이터 전체를 JSON 파일로 받기, **설정 가져오기**로 통째로 되돌리기. 가져오기는 현재 데이터를 모두 바꾸므로 먼저 내보내 두기.
- 이력 보관 규칙 3가지:
  - 같은 선택지를 편집 병합 시간(기본 5분) 안에 다시 저장하면 그 사이의 중간 본문은 이력에 남지 않음.
  - 선택지별 개수 상한을 넘으면 오래된 이력부터 변경 기록 없이 삭제.
  - 총량·기간 상한으로 지운 이력은 변경 기록에 한 줄 남음.
- 데이터 형식 번호 3(0.3.3부터). 0.3.2 이하 판으로 되돌리면 데이터가 읽기 전용으로만 보임. 반대로 현재 판보다 새로운 판이 만든 데이터도 읽기 전용으로만 표시하고 저장 파일은 건드리지 않음.

## 문제 해결 표

| 화면 문구 | 원인 | 조치 |
| --- | --- | --- |
| 이름이 같은 페르소나가 여럿이라 … 편집 잠금 | 활성 페르소나 판별 불가 | 페르소나 이름을 서로 다르게 바꾸기. 페르소나 전환은 잠기지 않음 |
| 더 새로운 판이 만든 데이터라 읽기 전용 | 현재 판보다 새로운 판이 저장한 데이터 | 확장을 최신 판으로 업데이트하기 |
| 선택지 미지정으로 프롬프트에서 빠지는 항목 N개 | 항목이 쓰던 선택지가 삭제됨. 활성 선택지 목록에는 `(삭제된 선택지)`로 표시 | 편집 탭 ▸ 해당 항목 ▸ 활성 선택지 다시 고르기 |
| 에셋 목록 불러오기 실패 | 그림 목록(sprites) 요청 실패 | 에셋 탭의 **다시 시도** 누르기 |
| `{{pimg::…}}`가 글자로 남음 | 해당 이름의 그림이 폴더에 없음, 또는 목록 요청 실패 | 에셋 탭의 파일 이름과 비교하기. 목록 요청 실패였다면 채팅 다시 열기 |
| 항목 제목이 바뀌어 항목별 가져오기 불가 | 외부 수정에서 항목 제목 줄이 지워졌거나 순서가 바뀜 | **되돌리기** 누르기, 또는 관리자에서 직접 수정하기 |
| 항목 제목 "없음" 설정으로 항목별 가져오기 불가 | 본문이 여러 항목에 있는데 항목 제목 형식이 `없음`이라 나눌 기준이 없음 | **되돌리기** 누르기, 또는 관리자에서 직접 수정하기 |

## 개발

```bash
npm install     # 스모크 테스트용 playwright (단위 테스트에는 불필요)
npm test        # 문법 검사 + 단위 테스트 (Node 20 이상, Windows 포함)
npm run smoke   # 헤드리스 브라우저로 모든 화면 구동, 스크린샷은 test/browser/out/
```

- 스모크 테스트 브라우저: `npx playwright install chromium`으로 받기, 또는 설치된 Chrome·Edge 사용하기(`PW_CHANNEL=chrome npm run smoke`, PowerShell은 `$env:PW_CHANNEL='chrome'; npm run smoke`).
- 화면 문구 규칙(문장 끝, 지시어, `strings.js` 밖의 한글 문장)은 `test/wording.test.mjs`가 검사.

### 파일 구조

```
index.js               진입점: 이벤트 연결, 채팅 그림, 그리팅 {{user}} 동기화, 해제
modules/
  state.js             현재 페르소나와 그 데이터 (유일한 출처), 설명문 쓰기 판단
  ctx.js               활성 페르소나 식별
  store.js             데이터 모델, 기본값, 형식 이행
  compose.js           항목 → 설명문 조합, SillyTavern에 쓰기, 외부 수정본 항목별 분할
  classify.js          제목 줄로 항목 분류
  history.js           이력, 상한, 되돌리기, 단어 단위 차이
  roster.js            페르소나 목록 정렬·그룹
  search-pure.js       검색, 언어 판단(대화 맥락 가중 투표), 페이지
  greeting.js          그리팅의 {{user}} 이름 동기화
  framing.js           이미지 위치·크기(자르기) 계산
  assets.js            sprites API, {{pimg::}}, 아바타 쓰기, 매크로
  manager-pure.js      관리자 화면 순수 로직
  quickbar-pure.js     빠른 패널 순수 로직
  dom.js               세 화면 공용 DOM 도우미
  quickbar.js          빠른 패널
  manager.js           관리자 화면
  settings-ui.js       설정 서랍
  strings.js           화면에 보이는 모든 문장
style.css              SillyTavern 테마 변수로 색을 만드는 스타일
test/
  run.mjs              문법 검사 + 단위 테스트 실행기 (npm test)
  *.test.mjs           단위 테스트
  browser/             스모크 테스트 (SillyTavern 모형 + playwright)
```

- `*-pure.js`, `store`, `compose`, `classify`, `history`, `roster`, `framing`, `greeting`은 DOM과 SillyTavern 없이 Node에서 그대로 테스트됨.
- 화면 모듈의 핸들러는 컨텍스트와 화면 요소를 보관하지 않고 실행 시점에 다시 읽음.
